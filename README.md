# Mater

Your coding agents, in one calm workspace.

Bring Codex, Claude Code and Cursor together in a local-first Mac app, using your own agent accounts.

[**Download for Mac**](https://getmater.app/download) · [Website](https://getmater.app) · [Getting started](https://getmater.app/install) · [Release notes](https://github.com/mikeylaz/mater-downloads/releases)

## Install

**Apple Silicon (M1 or newer) · macOS 13 or later · Beta**

1. Download the DMG and open it.
2. Drag **Mater Beta** into **Applications**, then open it.
3. Connect an installed, signed-in Codex, Claude Code or Cursor CLI in **Agent connections**.

This beta is locally signed and isn’t Apple notarized yet. If macOS blocks it, choose **System Settings → Privacy & Security → Open Anyway**. See the [installation guide](https://getmater.app/install) for approval, first use and updating.

Use a disposable project first and keep backups. Closing the window leaves active work running; use **Settings → Diagnostics → Pause queue and stop active work** to stop execution. Agents send prompts, code and tool data to their providers under your accounts and permissions.

This repository hosts Mater’s app downloads, release notes and [feedback](https://github.com/mikeylaz/mater-downloads/issues). The application source is maintained separately in a private repository. GitHub’s source-code ZIP and tarball are not the app; download the DMG or Mater app ZIP under release Assets.
